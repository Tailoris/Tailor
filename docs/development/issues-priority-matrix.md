# 问题优先级评估矩阵

## 1. 评估标准

| 维度 | 权重 | 评估标准 |
|------|------|----------|
| 业务影响 | 40% | 核心功能影响程度、用户数量、业务收入影响 |
| 安全风险 | 30% | 数据泄露风险、系统入侵风险、合规风险 |
| 技术复杂度 | 20% | 修复难度、代码改动范围、回归测试范围 |
| 时间紧迫性 | 10% | 上线时间要求、依赖关系、资源可用性 |

## 5. 修复验证流程

```
待修复 → 分析 → 开发 → 自测 → 代码审查 → 单元测试(≥80%) → 集成测试 → 功能验证 → 已验证
```

### 验证检查清单

| 阶段 | 检查项 | 责任人 |
|------|--------|--------|
| 开发完成 | 代码编译通过 | 开发 |
| 自测完成 | 功能验证通过 | 开发 |
| 代码审查 | 2人审查通过 | 审查者 |
| 单元测试 | 覆盖率 ≥ 80% | 开发 |
| 集成测试 | 接口测试通过 | 测试 |
| 功能验证 | 业务流程验证通过 | 测试 |
