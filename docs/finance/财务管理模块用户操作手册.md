# 财务管理模块用户操作手册

## 1. 概述

欢迎使用裁智云平台管理后台财务管理模块。本模块提供完整的财务业务管理功能，帮助管理员高效处理平台财务相关事务。

## 2. 功能模块介绍

### 2.1 交易流水

**功能定位**：记录和管理平台所有资金变动记录

**操作说明**：

| 操作 | 说明 |
|-----|------|
| 查询 | 通过订单号、商家名称、用户名称、交易类型、状态、时间范围等条件筛选 |
| 详情查看 | 点击交易记录查看完整交易信息，包括关联订单、支付方式、金额等 |
| 导出 | 支持导出Excel格式的交易流水报表 |

**交易类型说明**：

| 类型 | 说明 |
|-----|------|
| payment | 支付交易 |
| refund | 退款交易 |
| settlement | 结算交易 |
| fee | 费用扣除 |

**交易状态说明**：

| 状态 | 说明 |
|-----|------|
| pending | 处理中 |
| success | 成功 |
| failed | 失败 |

### 2.2 收入统计

**功能定位**：多维度数据分析，实时掌握平台收入情况

**操作说明**：

| 操作 | 说明 |
|-----|------|
| 查看统计卡片 | 展示今日/本周/本月/本年收入，以及订单数、转化率、客单价 |
| 趋势图 | 查看收入趋势变化，支持切换日/周/月视图 |
| 明细查看 | 点击统计卡片可查看详细收入构成 |

**统计指标说明**：

| 指标 | 说明 |
|-----|------|
| 今日收入 | 当天00:00-当前时间的收入总额 |
| 昨日收入 | 昨天00:00-24:00的收入总额 |
| 本周收入 | 本周一至当前的收入总额 |
| 本月收入 | 本月1日至当前的收入总额 |
| 本年累计 | 本年1月1日至当前的收入总额 |
| 订单数量 | 统计周期内的订单总数 |
| 转化率 | 下单用户数/访问用户数 × 100% |
| 客单价 | 收入总额/订单数量 |

### 2.3 结算管理

**功能定位**：处理商家结算申请，管理资金拨付

**操作说明**：

| 操作 | 说明 |
|-----|------|
| 查询结算 | 通过商家名称、结算状态、时间范围筛选结算记录 |
| 审核结算 | 对待审核的结算申请进行审批，可通过或拒绝 |
| 批量结算 | 勾选多个结算申请，批量审核通过 |
| 打款确认 | 审核通过后，确认打款状态 |

**结算流程**：

```
商家提交结算申请 → 财务审核 → 审核通过 → 打款 → 完成
                    ↓
                  审核拒绝 → 终止结算
```

**结算状态说明**：

| 状态 | 说明 |
|-----|------|
| pending | 待审核 |
| approved | 已审核 |
| paid | 已打款 |
| failed | 打款失败 |

### 2.4 退款管理

**功能定位**：处理用户退款申请，保障用户权益

**操作说明**：

| 操作 | 说明 |
|-----|------|
| 查询退款 | 通过订单号、用户名称、退款状态、时间范围筛选 |
| 审核退款 | 对退款申请进行审批，支持通过或拒绝 |
| 查看详情 | 查看退款申请的详细信息，包括退款原因、订单信息等 |

**退款流程**：

```
用户提交退款申请 → 商家审核 → 财务处理 → 退款完成
                    ↓
                  商家拒绝 → 用户申诉 → 平台仲裁
```

**退款状态说明**：

| 状态 | 说明 |
|-----|------|
| pending | 待审核 |
| approved | 已通过 |
| rejected | 已拒绝 |
| processing | 处理中 |
| completed | 已完成 |

**退款类型说明**：

| 类型 | 说明 |
|-----|------|
| full | 全额退款 |
| partial | 部分退款 |

### 2.5 财务报表

**功能定位**：生成和导出各类财务报表，支持决策分析

**操作说明**：

| 操作 | 说明 |
|-----|------|
| 生成报表 | 选择报表类型和时间周期，生成财务报表 |
| 查看报表 | 查看已生成的报表内容 |
| 导出报表 | 支持导出Excel/PDF格式报表 |
| 删除报表 | 删除不需要的报表记录 |

**报表类型说明**：

| 类型 | 说明 |
|-----|------|
| daily | 日报表 |
| weekly | 周报表 |
| monthly | 月报表 |
| quarterly | 季度报表 |
| yearly | 年报表 |

### 2.6 费用配置

**功能定位**：管理平台各类费用参数，灵活配置收费标准

**操作说明**：

| 操作 | 说明 |
|-----|------|
| 查询配置 | 查看所有费用配置列表 |
| 新增配置 | 创建新的费用类型配置 |
| 编辑配置 | 修改已有费用配置的参数 |
| 启用/禁用 | 控制费用配置的生效状态 |

**费用配置参数说明**：

| 参数 | 说明 |
|-----|------|
| 费用类型 | 费用的唯一标识 |
| 费用名称 | 费用的显示名称 |
| 费率 | 按金额比例收取的费用比例（%） |
| 固定金额 | 固定收取的费用金额 |
| 最低费用 | 最低收取金额 |
| 最高费用 | 最高收取金额 |
| 描述 | 费用的详细说明 |

## 3. 快速操作指南

### 3.1 查看交易流水

1. 登录平台管理后台
2. 在左侧导航栏点击「财务管理」→「交易流水」
3. 使用筛选条件查找特定交易记录
4. 点击交易记录查看详情

### 3.2 审核结算申请

1. 在左侧导航栏点击「财务管理」→「结算管理」
2. 在结算列表中找到状态为「待审核」的记录
3. 点击操作列的「审核」按钮
4. 在弹出的审核窗口中选择「通过」或「拒绝」并填写审核意见
5. 点击确认完成审核

### 3.3 处理退款申请

1. 在左侧导航栏点击「财务管理」→「退款管理」
2. 在退款列表中找到状态为「待审核」的记录
3. 点击操作列的「审核」按钮
4. 查看退款详情和退款原因
5. 选择「通过」或「拒绝」并填写处理意见
6. 点击确认完成处理

### 3.4 生成财务报表

1. 在左侧导航栏点击「财务管理」→「财务报表」
2. 点击「生成报表」按钮
3. 选择报表类型（日报/周报/月报/季报/年报）
4. 选择报表周期
5. 点击「确认生成」
6. 等待报表生成完成后，可查看或导出

### 3.5 配置费用参数

1. 在左侧导航栏点击「财务管理」→「费用配置」
2. 点击「新增配置」按钮
3. 填写费用类型、名称、费率等参数
4. 设置最低和最高费用限制
5. 填写费用描述
6. 点击「保存」完成配置

## 4. 权限说明

| 角色 | 可执行操作 |
|-----|-----------|
| 超级管理员 | 全部操作权限 |
| 财务管理员 | 全部操作权限 |
| 运营人员 | 查看数据、导出报表 |
| 普通用户 | 无权限 |

## 5. 注意事项

1. **结算审核**：审核结算申请前，请仔细核对商家信息和结算金额，确保无误
2. **退款处理**：处理退款时，请确认订单状态和退款金额，避免重复退款
3. **费用配置**：修改费用配置后，新配置将在下一次交易时生效，已有交易不受影响
4. **报表导出**：导出大量数据时，建议分批导出，避免浏览器卡顿
5. **数据安全**：财务数据属于敏感信息，请妥善保管账号密码，定期更换

## 6. 常见问题

### Q1：为什么看不到某些交易记录？

A：请检查筛选条件是否设置正确，特别是时间范围和交易状态。如果仍然无法找到，请联系系统管理员确认权限设置。

### Q2：结算申请审核后多久会打款？

A：审核通过后，系统会自动发起打款流程，通常在1-3个工作日内完成。如果超过3个工作日仍未到账，请联系财务人员核实。

### Q3：如何处理部分退款？

A：在退款审核页面，选择「部分退款」类型，输入退款金额（必须小于订单总金额），然后确认处理。

### Q4：财务报表生成需要多长时间？

A：报表生成时间取决于数据量大小，通常在几秒钟到几分钟之间。大数据量的年度报表可能需要更长时间，请耐心等待。

### Q5：费用配置修改后会影响历史交易吗？

A：不会。费用配置修改仅对修改之后的新交易生效，历史交易仍按原有配置计算费用。
