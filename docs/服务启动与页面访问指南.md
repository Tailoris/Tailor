### 2.5 认证方式与权限

#### 平台管理后台

- **登录地址**: `/admin/login`
- **认证方式**: JWT Token
- **权限控制**: RBAC角色权限
- **必需角色**: `SUPER_ADMIN` 或 `PLATFORM_ADMIN`
- **Token存储**: `localStorage` 的 `token` 和 `permissions` key

#### 商家管理后台

- **登录地址**: `/merchant/login`
- **认证方式**: JWT Token
- **权限控制**: 商家店铺权限
- **Token存储**: `localStorage` 的 `merchant_token` key

#### PC商城

- **登录地址**: `/login`
- **认证方式**: JWT Token
- **Token存储**: `localStorage` 的 `user_token` key

## 三、启动/停止命令

### 3.1 前置条件

在启动服务前，需完成以下准备工作：

```bash
# 1. 进入项目目录
cd /home/tailor/Tailoris

# 2. 创建环境变量文件（从模板复制）
cp deploy/.env.example deploy/.env

# 3. 编辑 .env 文件，配置数据库密码等敏感信息
vim deploy/.env

# 4. 确保 Docker 已启动
systemctl start docker  # Linux
# 或在 Windows/Mac 启动 Docker Desktop

# 5. （可选）构建后端镜像
cd tailor-is
mvn clean package -DskipTests
cd ..
```

### 3.2 启动服务

#### 方式一：使用分组启动脚本（推荐）

```bash
# 启动中间件 + 核心交易服务
bash deploy/scripts/dev-start.sh infra core-trade

# 启动中间件 + AI版权链服务
bash deploy/scripts/dev-start.sh infra core-ai-chain

# 启动中间件 + 所有服务（注意：最多12个Java容器）
bash deploy/scripts/dev-start.sh infra core-trade core-ai-chain
```

#### 方式二：使用 Docker Compose 命令

```bash
cd deploy

# 启动中间件
docker compose -f docker-compose.services.yml up -d mysql redis rabbitmq nacos mongodb

# 等待中间件健康（约30-60秒）
sleep 60

# 启动核心交易服务
docker compose -f docker-compose.services.yml --profile core-trade up -d

# 启动AI版权链服务
docker compose -f docker-compose.services.yml --profile core-ai-chain up -d

# 启动社区论坛服务
docker compose -f docker-compose.services.yml --profile light-forum up -d

# 启动线上学堂服务
docker compose -f docker-compose.services.yml --profile light-edu up -d

# 启动数据分析服务
docker compose -f docker-compose.services.yml --profile light-data-supply up -d
```

#### 方式三：启动前端服务

```bash
# PC商城
cd tailor-is-frontend/pc-mall
npm run dev

# 平台管理后台
cd tailor-is-frontend/platform-admin
npm run dev

# 商家管理后台
cd tailor-is-frontend/merchant-admin
npm run dev
```

### 3.3 停止服务

#### 方式一：使用一键停止脚本

```bash
# 停止所有业务服务（保留中间件）
bash deploy/scripts/dev-stop-all.sh
```

#### 方式二：使用 Docker Compose 命令

```bash
cd deploy

# 停止所有服务
docker compose -f docker-compose.services.yml down

# 停止指定分组
docker compose -f docker-compose.services.yml --profile core-trade down

# 停止并删除数据卷（谨慎使用，会清空数据库）
docker compose -f docker-compose.services.yml down --volumes --remove-orphans
```

#### 方式三：停止前端服务

```bash
# 在前端项目目录按 Ctrl+C 停止开发服务器
# 或查找进程并终止
kill $(cat /tmp/tailoris-frontend.pid) 2>/dev/null || true
```

### 3.4 重启服务

```bash
# 重启指定服务
docker restart tailor-is-admin

# 重启所有业务服务
docker compose -f docker-compose.services.yml restart

# 重启前端服务
cd tailor-is-frontend/platform-admin
npm run dev  # 先按 Ctrl+C 停止，再重新启动
```

### 3.5 状态检查

```bash
# 查看所有运行中的容器
docker ps

# 查看容器状态（含资源占用）
docker stats

# 查看容器日志
docker logs -f tailor-is-admin
docker logs -f tailor-is-gateway

# 查看服务健康状态
bash deploy/scripts/health-check.sh

# 查看 Nacos 服务注册情况
curl http://localhost:8848/nacos/v1/ns/catalog/services?pageNo=1&pageSize=100
```

### 3.6 常见错误处理

#### 错误：端口占用

```bash
# 查找占用端口的进程
lsof -i :9000
# 或
netstat -tlnp | grep 9000

# 杀死占用进程
kill -9 <PID>
```

#### 错误：容器启动失败

```bash
# 查看容器日志
docker logs <容器名>

# 查看容器详细信息
docker inspect <容器名>

# 重新构建并启动
docker compose -f docker-compose.services.yml up -d --build
```

#### 错误：数据库连接失败

```bash
# 检查数据库容器状态
docker logs tailor-is-mysql

# 检查数据库是否可访问
mysql -h 127.0.0.1 -u root -p -e "SELECT 1"

# 检查网络连接
docker exec tailor-is-admin ping mysql -c 3
```

#### 错误：前端页面白屏

```bash
# 检查控制台错误（浏览器F12）
# 检查 API 代理是否正常
curl http://localhost:3003/api/v1/admin/dashboard/stats

# 检查网关是否正常
curl http://localhost:9000/api/v1/admin/dashboard/stats

# 清理 Vite 缓存
rm -rf node_modules/.vite
npm run dev
```

#### 错误：服务注册失败

```bash
# 检查 Nacos 是否正常
curl http://localhost:8848/nacos/v1/console/health/liveness

# 检查服务日志中的注册信息
docker logs -f tailor-is-admin | grep nacos

# 检查网络是否连通
docker exec tailor-is-admin ping nacos -c 3
```

- **路径**: `/admin/login`
- **功能**: 管理员登录认证
- **字段**: 用户名、密码、验证码
- **认证**: JWT Token，登录成功后存储到 `localStorage`

### 4.4 核心业务流程

#### 订单创建流程

```
用户浏览商品 → 加入购物车 → 结算页面 → 选择支付方式 → 提交订单
    ↓
支付服务处理 → 订单状态更新 → 通知商家 → 商家发货 → 用户确认收货
    ↓
订单完成 → 财务结算 → 商家提现
```

#### 纸样定制流程

```
用户提交需求 → 平台审核 → 分配版师 → 初版设计 → 用户确认/修改
    ↓
修改优化 → 最终交付 → 版权存证 → AI侵权检测 → 完成
```

#### 商家入驻流程

```
商家申请入驻 → 资质审核 → 实操考核 → 质保金校验 → 开通店铺
    ↓
店铺配置 → 商品上架 → 开始运营
```

#### 财务管理流程

```
交易产生 → 交易流水记录 → 收入统计 → 结算周期到达 → 商家发起结算
    ↓
平台审核 → 确认结算金额 → 打款处理 → 结算完成
```

### E. 注意事项

1. **启动顺序**: 必须先启动中间件（infra），再启动业务服务
2. **端口冲突**: 确保端口 3001/3002/3003/9000/8081 未被其他程序占用
3. **环境变量**: `.env` 文件必须正确配置，否则服务无法启动
4. **内存限制**: 单次最多启动 12 个 Java 容器，避免资源不足
5. **前端代理**: 开发环境前端请求自动代理到网关（localhost:9000）
6. **缓存清理**: 修改路由配置后需清理 Vite 缓存并重启开发服务器
