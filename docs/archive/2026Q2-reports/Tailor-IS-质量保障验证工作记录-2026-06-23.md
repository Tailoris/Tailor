## 二、关键未修复项修复方案

### 2.1 C-03：AES 密钥配置错误

- **修复目标**: 统一 AES 密钥为 Base64 编码格式，移除原始字符串回退分支
- **技术路径**: 修改 `AesGcmCrypto.decodeKey()` 方法，仅保留 Base64 解码
- **实施步骤**:
  1. 定位 `tailor-is-common/src/main/java/com/tailoris/common/crypto/AesGcmCrypto.java`
  2. 移除 `decodeKey()` 中的 try-catch 回退分支
  3. 直接返回 `Base64.getDecoder().decode(key)`
  4. 添加注释说明密钥格式要求

### 2.2 C-14：Actuator 端点暴露

- **修复目标**: HTTPS server 块补充 Actuator deny 规则
- **技术路径**: 在 nginx/default.conf 的 HTTPS 块添加 location deny
- **实施步骤**:
  1. 定位 HTTPS server 块（line 161 附近）
  2. 添加 `location ~* /actuator/ { deny all; return 403; }`
  3. 确保与 HTTP 块规则一致

### 2.3 H-01：id_card 列长度不足

- **修复目标**: 扩展 id_card 字段以容纳加密后数据
- **技术路径**: 修改 SQL 建表脚本字段长度
- **实施步骤**:
  1. 定位 `tailor-is/sql/01_user_system.sql`
  2. `id_card VARCHAR(64)` → `VARCHAR(255)`

### 2.4 H-11：Nacos namespace 默认值为空

- **修复目标**: 统一 namespace 默认值为 prod
- **技术路径**: 修改所有 bootstrap.yml 的 namespace 配置
- **实施步骤**:
  1. 全局搜索 `${NACOS_NAMESPACE:}`
  2. 替换为 `${NACOS_NAMESPACE:prod}`
  3. 验证 18 个文件 35 处全部更新

### 2.5 H-17：AES-GCM 密钥存 localStorage

- **修复目标**: 密钥存储改为 sessionStorage，会话结束自动清除
- **技术路径**: 修改所有前端 crypto.ts 的存储 API
- **实施步骤**:
  1. 定位 4 个前端应用的 crypto.ts
  2. `localStorage` → `sessionStorage`
  3. 更新注释说明修复原因
  4. 验证 0 处代码残留（注释除外）

### 2.6 M-09：InventoryService 逐条 UPDATE

- **修复目标**: 改为批量 UPDATE 减少数据库往返
- **技术路径**: 使用 JdbcTemplate.batchUpdate + BatchPreparedStatementSetter
- **实施步骤**:
  1. 修改 deductStock/releaseStock/confirmDeduct 三个方法
  2. 构建 BatchPreparedStatementSetter
  3. 检查批量结果数组

### 2.7 M-18：CSP 头部 unsafe-inline

- **修复目标**: 移除 CSP 中的 unsafe-inline
- **技术路径**: 修改 security-headers.conf
- **实施步骤**:
  1. style-src 和 script-src 移除 'unsafe-inline'
  2. 保留 'self' 策略
  3. 添加注释说明 nonce 替代方案
