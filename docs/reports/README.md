# 文档归档策略

本目录存放项目阶段性报告及核查清单。当文档不再需要频繁访问时，应归档至 `docs/archive/` 目录。

## 归档规则

| 条件 | 操作 |
|------|------|
| 文档创建超过 6 个月且未被引用 | 移至 `docs/archive/` |
| 文档中的任务/清单已全部完成 | 移至 `docs/archive/` |
| 被更新的版本替代的旧版报告 | 移至 `docs/archive/` |
| 季度核查报告 (上一季度) | 移至 `docs/archive/` |

## 归档流程

1. 确认文档已无活跃引用
2. 将文件移至 `docs/archive/` 目录
3. 在 `docs/archive/README.md` 中记录归档信息（文件名、归档日期、原因）
4. 提交时使用 `docs: archive outdated reports` 格式
