### M-01: SecureRandom 性能优化

| 字段 | 内容 |
|------|------|
| **问题描述** | `AuthController.java` L194 中 `SECURE_RANDOM` 是静态字段，多线程争用降低性能 |
| **影响分析** | 高并发登录场景（>100 QPS）下验证码生成延迟增加 |
| **修复方案** | 使用 `ThreadLocal<SecureRandom>` 替代静态字段 |
| **实施步骤** | 1) 替换 `private static final SecureRandom SECURE_RANDOM = new SecureRandom()` 为 `private static final ThreadLocal<SecureRandom> SECURE_RANDOM = ThreadLocal.withInitial(SecureRandom::new)` 2) 更新使用处 3) 并发压测验证 |
| **计划修复时间** | 2026-08-07 |
| **预估工作量** | 0.5 天 |
| **验证方法** | JMeter 并发登录压测，对比修复前后 P99 延迟 |
| **验证通过标准** | P99 延迟降低 > 20% |
