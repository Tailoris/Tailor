## 三、问题影响分析矩阵

### 3.1 M-01: SecureRandom 性能优化

| 维度 | 分析 |
|------|------|
| **影响范围** | `AuthController.java` L194 验证码生成 |
| **触发条件** | 高并发登录场景（> 100 QPS） |
| **影响程度** | 低 - SecureRandom 阻塞仅在高并发下可感知 |
| **修复方案** | 使用 ThreadLocal<SecureRandom> 或改用 ThreadLocalRandom |
| **修复代码量** | ~5 行 |
| **回滚风险** | 低 - 仅影响验证码生成逻辑 |
| **验证方法** | 并发登录压测，对比修复前后延迟 |

### 3.2 M-06: 测试覆盖率基线

| 维度 | 分析 |
|------|------|
| **影响范围** | 全项目 22 个微服务 |
| **触发条件** | 持续存在 |
| **影响程度** | 中 - 无法量化代码质量，回归测试覆盖不足 |
| **修复方案** | 1) 建立 JaCoCo 覆盖率报告 2) 核心模块优先补充测试 3) CI 集成覆盖率门禁 |
| **修复代码量** | 新增测试类，预计 50+ 测试文件 |
| **回滚风险** | 无 - 纯新增 |
| **验证方法** | JaCoCo 报告覆盖率 > 60% |
