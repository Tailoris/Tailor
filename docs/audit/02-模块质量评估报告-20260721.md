## 一、评估指标体系

### 1.1 进度评估指标

| 指标 | 计算公式 | 权重 |
|------|---------|------|
| 功能点完成率（FCR） | 已完成功能点数 / 规划功能点总数 × 100% | 30% |
| 计划达成率（PAR） | 按计划完成的功能点数 / 总功能点数 × 100% | 20% |
| 里程碑达成率（MAR） | 已达成里程碑数 / 规划里程碑总数 × 100% | 15% |

### 1.2 质量评估指标

| 指标 | 计算方式 | 权重 |
|------|---------|------|
| 代码规范符合度（CC） | 规则违规项检查通过率 | 20% |
| 测试通过率（TPR） | 通过测试数 / 总测试数 × 100% | 15% |
| 缺陷密度（DD） | 缺陷数 / 千行代码（KLOC） | 10% |
| 安全漏洞等级（SL） | 安全扫描结果评分（0-100） | 15% |
| 文档完整度（DC） | 已文档化功能点数 / 总功能点数 × 100% | 10% |

### 1.3 综合评分公式

```
模块综合分 = 0.25×FCR + 0.10×PAR + 0.05×MAR + 0.20×CC + 0.15×TPR + 0.10×DD + 0.15×SL
```

### 1.4 评级标准

| 等级 | 分数区间 | 说明 |
|------|---------|------|
| 🏆 A+ | 95-100 | 卓越 |
| ✅ A | 90-94 | 优秀 |
| ✅ B+ | 85-89 | 良好 |
| ⚠️ B | 80-84 | 合格 |
| ⚠️ C | 70-79 | 需改进 |
| 🔴 D | 60-69 | 不合格 |
| 🔴 F | 0-59 | 严重不足 |
