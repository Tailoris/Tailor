# 财务管理模块技术文档

## 1. 模块概述

财务管理模块是裁智云平台管理后台的核心模块之一，负责管理平台所有财务相关业务，包括交易流水、收入统计、结算管理、退款管理、财务报表和费用配置六大核心功能。

### 1.1 功能定位

| 功能模块 | 职责描述 |
|---------|---------|
| 交易流水 | 记录所有资金变动，提供交易查询、筛选、导出功能 |
| 收入统计 | 多维度收入数据分析，支持日/周/月/年统计 |
| 结算管理 | 处理商家结算申请，支持批量结算 |
| 退款管理 | 处理用户退款申请，支持部分退款 |
| 财务报表 | 生成各类财务报表，支持多格式导出 |
| 费用配置 | 管理平台各类费用参数，包括交易手续费、版权检测费等 |

## 2. API 接口规范

### 2.1 接口前缀

所有财务接口统一前缀：`/api/v1/admin/finance`

### 2.2 接口列表

| 接口路径 | HTTP方法 | 功能描述 |
|---------|---------|---------|
| `/transactions` | GET | 查询交易流水列表 |
| `/transactions/{id}` | GET | 查询单笔交易详情 |
| `/transactions` | POST | 创建交易记录 |
| `/transactions/{id}` | PUT | 更新交易状态 |
| `/revenue` | GET | 获取收入统计数据 |
| `/revenue/trend` | GET | 获取收入趋势 |
| `/settlements` | GET | 查询结算列表 |
| `/settlements/{id}` | PUT | 处理结算申请 |
| `/settlements/batch` | POST | 批量结算 |
| `/refunds` | GET | 查询退款列表 |
| `/refunds` | POST | 创建退款申请 |
| `/refunds/{id}` | PUT | 处理退款申请 |
| `/reports` | GET | 查询报表列表 |
| `/reports/generate` | POST | 生成财务报表 |
| `/reports/{id}/export` | GET | 导出报表 |
| `/fee-config` | GET | 查询费用配置列表 |
| `/fee-config/{id}` | PUT | 更新费用配置 |
| `/fee-config` | POST | 创建费用配置 |

### 2.3 数据模型

#### 2.3.1 TransactionInfo (交易信息)

```typescript
interface TransactionInfo {
  id: string;                    // 交易ID
  orderNo: string;               // 关联订单号
  merchantId: string;            // 商家ID
  merchantName: string;          // 商家名称
  userId: string;                // 用户ID
  userName: string;              // 用户名称
  amount: number;                // 交易金额
  type: 'payment' | 'refund' | 'settlement' | 'fee'; // 交易类型
  status: 'pending' | 'success' | 'failed'; // 交易状态
  paymentMethod: string;         // 支付方式
  createdAt: string;             // 创建时间
  completedAt?: string;          // 完成时间
  remark?: string;               // 备注
}
```

## 5. 数据安全

### 5.1 加密策略

- 交易金额、结算金额等敏感数字字段在前端展示时进行脱敏处理
- API传输使用HTTPS加密
- 数据库存储使用AES-256加密（遵循项目数据安全规则）

### 5.2 审计日志

所有财务操作必须记录审计日志，包括：
- 结算审核操作
- 退款处理操作
- 费用配置变更
- 报表导出操作

## 6. 性能优化

### 6.1 前端优化

1. **虚拟列表**：交易流水列表使用虚拟滚动，支持大数据量渲染
2. **组件懒加载**：路由组件使用懒加载，首屏加载时间优化
3. **请求缓存**：收入统计数据使用本地缓存，5分钟内不重复请求
4. **纯CSS标签**：表格内复杂组件替换为纯CSS实现，减少组件实例开销
5. **API超时降级**：请求超时自动使用Mock数据，保证页面可用性

### 6.2 后端优化

1. **数据库索引**：交易流水表按时间、商家ID建立联合索引
2. **分页查询**：列表查询默认分页，每页20条
3. **Redis缓存**：收入统计数据缓存10分钟
4. **异步报表生成**：报表生成使用异步任务队列

## 7. 跨模块数据流转

### 7.1 订单 → 交易

```
订单创建 → 订单支付 → 生成交易记录 → 更新订单状态
```

### 7.2 订单 → 退款

```
用户申请退款 → 创建退款记录 → 商家审核 → 财务处理 → 更新订单状态
```

### 7.3 商家 → 结算

```
订单完成 → 累计商家收入 → 自动生成结算申请 → 财务审核 → 打款
```

### 7.4 交易 → 报表

```
交易记录入库 → 定时任务汇总 → 生成报表数据 → 报表生成请求
```

## 8. 部署与集成

### 8.1 服务端口

- 前端：集成在平台管理后台，无需独立端口
- 后端服务：`finance-service`，端口 `8108`

### 8.2 环境配置

```yaml
# application.yml
server:
  port: 8108

spring:
  application:
    name: finance-service
  datasource:
    url: jdbc:mysql://mysql:3306/tailoris_finance
```

### 8.3 网关路由

```yaml
# 网关路由配置
- id: finance-service
  uri: lb://finance-service
  predicates:
    - Path=/api/v1/admin/finance/**
```

## 9. 异常处理

### 9.1 前端异常处理

| HTTP状态码 | 处理方式 |
|-----------|---------|
| 401 | 跳转登录页 |
| 403 | 提示无权限 |
| 400 | 显示业务错误信息 |
| 500 | 显示系统错误提示 |

### 9.2 后端异常处理

- 全局异常处理器捕获所有异常
- 业务异常返回HTTP 400 + 错误码
- 系统异常返回HTTP 500 + 通用错误信息
